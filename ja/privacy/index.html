Moonaは、カザフスタンを拠点とする Garbuzov Matvei（以下「当方」）が提供しています。プライバシーに関するお問い合わせは matveyvoronezh@gmail.com までお寄せください。

Moona は、レッスン、チェックイン、夜のルーティン、進捗状況の概要を通じて睡眠習慣を構築するのに役立ちます。現在のアプリは、Moona アカウントなしで動作します。コース記録はデバイス上で処理されます。当社はそれらの記録を受信するサーバーを運用しません。

アプリで使用される情報

使用する機能に応じて、Moona には以下が保存されます。

  • オプションの名前、住所の好ましい形式、および月のアバターの選択。
  • オンボーディングでは、睡眠の問題、習慣、目標、睡眠時間、Apple Watch の利用可能性について回答します。
  • 計画されたスケジュール、リマインダーの設定、コースの開始日、完了したレッスン、タスクの回答と進捗状況。
  • 睡眠の開始/終了時刻、その時刻のソース、入力したエネルギーと気分の評価。
  • 夜のチェックリストのエントリ、悩み、ブレインダンプテキスト、良い瞬間、その他の筆記練習の回答。
  • 連続記録、獲得したステッカー、および関連する日付。

この情報は、計画、レッスン、リマインダー、グラフ、成果、要約カードを提供します。フリーテキストのエントリは機密性が高い場合があります。アプリに残しておきたい内容のみを入力します。当社はお客様の情報を販売したり、広告やアプリ間追跡に使用したりすることはありません。現在のアプリには、サードパーティの広告、分析、クラッシュレポート SDK は含まれていません。

アップルヘルス

Appleの「ヘルスケア」のデータへのアクセスは任意で、Appleのアクセス許可設定によって管理されます。許可をいただいた場合、Moonaは睡眠分析データを読み取り、主な睡眠時間帯を推定して毎日の記録を入力します。選択した気分の評価を「心の状態」（State of Mind）として「ヘルスケア」に保存することもできます。Moonaが「ヘルスケア」に睡眠記録を書き込んだり、データベース全体を読み取ったりすることはありません。

ヘルスケアに接続しなくても、手動で睡眠に入ることができます。 Apple Health またはシステム設定で、Moona の Health 権限を変更できます。許可を取り消すと、対応する今後のアクセスが停止されます。以前に保存された Moona チェックインやヘルスに既に書き込まれたレコードは自動的に削除されません。それらの記録は個別に管理してください。

健康情報は、アプリの睡眠と健康機能に使用されます。当社は、HealthKit データを広告主、データ ブローカー、または当社独自のサーバーに送信したり、広告やマーケティング プロファイルに使用したりすることはありません。

ストレージ、ウィジェット、リマインダー

現在のアプリはコースのデータをお使いの端末に保存します。現在の構成では、MoonaのiCloud同期機能は有効になっていません。端末のバックアップ、「ヘルスケア」のデータ同期、その他お客様が有効にしたAppleのサービスには、お客様の設定とAppleのポリシーが適用されます。

ウィジェットを表示するために、Moona は、独自のウィジェット拡張機能と共有されるアプリ グループに小さなスナップショットを保存します。これには、計画された就寝/起床時間、コースの日付、タスクのテキスト、連続記録情報、チェックイン完了日/フラグが含まれます。個人的な日記のテキストは含まれません。ウィジェットとローカル通知により、ホーム画面またはロック画面に情報が表示される場合があります。それに応じて、プレースメントと通知プレビューを選択します。リマインダーはローカルでスケジュールされるため、プッシュ サーバーは必要ありません。

結果の保存と共有

要約画像を保存すると、Moona はその画像を写真に追加する許可を要求します。この機能は写真ライブラリを読み取りません。システム共有シートを介して要約カードを送信することも選択できます。カードには、睡眠、エネルギー、または進捗状況の情報が含まれる場合があります。共有する前に画像と受信者を確認してください。写真に保存されたコピー、または別のアプリに送信されたコピーは、Moona とは別に管理され、受信者の慣行に従います。

購入とサードパーティ

Apple は、独自の規約とプライバシー ポリシーに基づいて、App Store のダウンロードと Apple が管理する取引を処理します。 Moona の現在の購入スキャフォールディングは、検証済みの資格をクエリし、StoreKit を通じて復元をリクエストできます。支払いカード番号は受け取れません。

RevenueCat は現在のアプリに統合されていません。サブスクリプション サービスまたは別の SDK を使用するバージョンを配布する前に、このポリシーを更新して、プロバイダー、受信する情報、およびその目的を特定します。現在のポリシーを、将来の SDK が情報を受け取らないことを示唆するために使用してはなりません。

ソース リンクをたどる場合、Web サイトを開く場合、またはサードパーティ サービスと共有する場合は、そのサービス独自のプライバシー慣行が適用されます。 Apple のプライバシー ポリシーは、apple.com/legal/privacy でご覧いただけます。

サポートコミュニケーション

当社に電子メールをお送りいただく場合、当社はお客様の電子メール アドレス、メッセージ、添付ファイル、およびお客様が含めることを選択した情報を受け取ります。当社は、お客様のリクエストに回答し、トラブルシューティングを行い、該当する義務を履行するためにそれらを使用します。弊社のサポート メールボックスは Gmail によってホストされているため、電子メールは関連する電子メール プロバイダーを通じて処理されます。リクエストに必要な場合を除き、医療関連のエクスポート、個人的な日記のエントリ、またはその他の機密資料の送信は避けてください。可能な場合はスクリーンショットを編集します。

Apple Mail がデバイスで設定されている場合、「お問い合わせ」を選択すると、Moona 内で Apple のメール作成インターフェイスが開きます。ドラフトには、トラブルシューティングができるようにアプリと iOS のバージョンが含まれています。送信する前に編集または削除できます。 Moona は、睡眠記録、気分評価、日記エントリまたはログを自動的に添付しません。メールが利用できない場合は、サポート アドレスをコピーして、通常のメール アプリを使用できます。

ドキュメント Web サイト

私たちの公開ドキュメント ページは GitHub ページでホストされています。 GitHub は、GitHub にサインインしているかどうかに関係なく、セキュリティ目的で訪問者の IP アドレスを記録します。処理方法については、GitHub プライバシーに関する声明 を参照してください。これらの静的ページには、広告、分析、追跡スクリプト、外部フォントまたは Cookie は追加されません。ドキュメント ページにアクセスしても、Moona コース記録にはアクセスできません。

保持、選択、リクエスト

ローカルのコース記録は、アプリのストレージに保存されている間も利用できます。利用可能なコントロールを使用して設定とプロファイルの詳細を更新したり、権限を取り消したり、リマインダーを無効にしたり、ウィジェットを削除したりできます。アプリの削除はオフロードとは異なります。オフロードではアプリのデータが保持されます。アプリを削除しても、ヘルスケア記録、保存された画像、共有コピー、Apple バックアップは削除されません。共有拡張機能ストレージとバックアップには、iOS によって管理される個別のライフサイクルがある場合があります。

当社はあなたのコースやジャーナル記録のサーバー側のコピーを保持しておらず、それらを取得したり、リモートで削除したりすることはできません。該当するデバイス コントロールの検索やプライバシー リクエストの作成については、matveyvoronezh@gmail.com にお問い合わせください。サポート メッセージは、リクエストおよび適用される法的義務、セキュリティ義務、紛争上の義務を処理するために合理的に必要な期間のみ保持されます。不要な添付ファイルは、不要になったら削除する必要があります。

適用法が許可する場合、お客様は、当社が保有する個人情報へのアクセス、修正、削除、制限またはポータビリティを要求したり、特定の処理に異議を唱えたり、同意を撤回したり、管轄のプライバシー当局に苦情を申し立てたりすることができます。当社は、リクエストに適用される法律に基づいてリクエストを処理し、場合によってはお客様の身元確認が必要となる場合があります。リクエストを行うためだけにプライベートのコース記録を送信する必要はありません。

当社が直接受け取った情報について、当社の処理根拠（そのような根拠が必要な場合）には、お客様からリクエストされたサポート サービスの処理、問題の解決とサービスの保護における正当な利益、および法的義務の遵守が含まれます。オプションのヘルスアクセスと権限は引き続きお客様の制御下にあります。同意が法的に必要な場合は、関連する処理の前に同意を取得する必要があります。

国際的な処理とセキュリティ

演算子は カザフスタン に基づいています。他の場所から当社に連絡する場合、あなたの通信はその場所および電子メールプロバイダーが使用する場所で処理される場合があります。適用される法律で安全策が必要な転送には、それらの安全策を使用する必要があります。ローカルのみのコース処理自体は、レコードを カザフスタン のオペレーターに送信しません。

Moona は、プラットフォームのストレージと許可のメカニズムを使用します。パスコードでデバイスを保護し、ソフトウェアを常に最新の状態に保ちます。完全に安全であることを保証できるストレージや通信方法はありません。

子どもたちと変化

Moona のコースは大人向けに設計されており、子供向けではありません。当社は、サポートを通じて故意に子供の個人情報を要求することはありません。お子様が当社に個人情報を送信したと思われる場合は、対処できるよう当社までご連絡ください。

当社は慣行が変更された場合にはこのポリシーを改訂し、公開された改訂の発効日を特定します。重大な変更は、適用される法律の要求に応じて通知されます。
